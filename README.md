# 📊 SuperCorp Admin Dashboard – TailwindCSS + Chart.js

**SuperCorp Dashboard** is a modern, responsive **Admin Panel UI** built using **Tailwind CSS** and **Chart.js**, featuring clean layout, interactive visual charts, and a professional analytics interface.
Perfect for SaaS platforms, CRM systems, product analytics dashboards, or educational showcase projects.

## ⚡ Features

* 📊 Interactive charts powered by Chart.js
* 🎛 Dashboard layout using Flexbox + CSS Grid
* 🎯 KPI cards for Revenue, Sales & Conversion
* 🧭 Sidebar navigation menu
* 👤 Profile & Logout section on navbar
* 🌍 Top Countries & Top Channels analytics
* 🧱 Built entirely with Tailwind utility classes
* 🪄 Clean, responsive, and easy to customize

## 🚀 Getting Started Locally

### 1️⃣ Clone this repository

```bash
git clone https://github.com/magheswaran/DashBoard.git
cd DashBoard
```

---

### 2️⃣ Install Dependencies

```bash
npm install
```

---

### 3️⃣ Run Tailwind Build

```bash
npx tailwindcss -i ./src/input.css -o ./output.css --watch
```

---

### 4️⃣ Open the Project

Simply open:

```bash
index.html
```

(or drag into browser)
